# Washly Mobile — Release Notes

Версия: v1.0.1(11) 
Дата релиза: 2025-11-08 (Asia/Almaty)

Кратко

Основной функционал QR перенесён на страницу карты. Экран CarOwnerDashboard в ближайших релизах будет удалён. Добавлены правки по шапкам, кнопкам «Назад», интеграции 2ГИС и настройкам автомойки.

Patch list (изменения)

Карта

Перенос всего QR-флоу на /map: сканер, scanBooking, pollSession, предзаполнение доп.услуг, pay(cash|card), автополлинг статусов.

Категории (Автомойка/СТО/Шиномонтаж/Масло), фильтры, «Открыто сейчас», сортировки «ближе/рейтинг/цена».

Фокус на маркер + автоподъём шторки бронирования (BookingModal).

Хэндлеры выбора бокса/слотов/кузова/допов, подсчёт цены.

QR-сессии

Безопасная инициализация/сброс, единый поллинг с очисткой таймеров, отображение expiresIn, статусов initiated/awaiting_extras/cash_waiting_approval/paid/expired/closed.

Подтверждение наличных (админ: cashApprove), защита от повторного клика.

Мои записи

Экран /my-bookings: шапка с кнопкой «Назад» слева (вровень с заголовком), действия: «Позвонить», «На карте», «Отменить», состояние «Отмена…».

Статистика (клиент)

Экран StatsScreen: добавлена кнопка «Назад» в шапку (на одном уровне с тайтлом).

Админка автомойки

Экран настроек: выбор точки через 2ГИС (поиск/карта), автоподстановка адреса/фото (если есть), ввод графика работы (валидация HH:MM), загрузка собственного фото.

Динамическая настройка: количество боксов, цены по кузовам, базовые услуги и кастомные услуги.

Отправка формы multipart/form-data (только локальное фото как файл, остальное — JSON поля).

Загрузка справочников кузовов/услуг из стора.

Дашборд (владелец)

Сегменты День/Неделя/Месяц/Год/Период, экспорт статистики в Excel и PDF.

Обновление списка «Сегодняшние брони» с периодическим пуллингом.

Прочее

Унификация форматирования телефонов, нормализация названий допов, аккуратная обработка ошибок (Alert), мелкие UX-фиксы.

Потенциальные breaking changes

Пользовательские сценарии, ранее завязанные на CarOwnerDashboard, должны идти через экран карты.

Нельзя параллельно запускать старый QR-процесс и новый — таймеры в новом флоу агрессивно чистятся.

Переменные окружения

API_BASE_URL — базовый URL без /api для некоторых запросов из админки.

GIS_API_KEY — ключ 2ГИС, используется в AdminPlacePicker/TwoGisSearchModal и на карте.

Тест-чеклист (кратко)

Карта: открыть → выбрать мойку → открыть шторку → слоты/допы/цена считаются корректно.

QR: со страницы карты отсканировать код → увидеть статус, предзаполненные допы → оплатить «наличные» (админ подтверждает).

My Bookings: кнопка «Назад», звонок, «На карте», отмена с прогрессом.

Админка: выбрать объект 2ГИС, задать время работы, добавить боксы/цены/услуги, загрузить фото → «Сохранить изменения».

Экспорт: Excel/PDF на выбранном диапазоне.

Известные ограничения

Оплата картой — заглушка (UI-сообщение «Скоро»).

Не все карточки мойки содержат min/avg цены — сортировка по цене в таких случаях мягкая.
